# 結の郷 古着出品アシスト（デモ）

写真のアップロード、色ムラ候補を画像上の番号付きマーカーで表示、衣服の部位選択、職員の確認、商品説明文生成、簡易背景差し替え、コピーと保存ができます。

本格的なAIによる汚れ・毛玉・ほつれ検出は搭載されていません。局所的な明暗差による簡易検出です。

## Vercel 公開

このフォルダを GitHub リポジトリへアップロードし、Vercel の New Project → Import Git Repository から取り込みます。フレームワークは Other、Root Directory はこのフォルダ、環境変数は不要です。Deploy でURLが発行されます。
